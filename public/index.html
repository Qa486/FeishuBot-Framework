飞书智能助手
Feishu Bot Framework

为飞书打造的模块化机器人 SaaS 框架。无需编程基础，点点鼠标即可配置自动回复、定时通知、问卷调查、FAQ 助手和消息转发。

工作原理
3 步快速上线
1

创建飞书应用

在飞书开放平台创建企业自建应用，获取 App ID 和 Secret

2

配置参数

修改 config_example.yaml，填入凭证并启用所需模块

3

一键部署

Docker 一行命令启动，或手动 pip 安装 + python bot.py

核心功能
5 大模块，即插即用

每个模块独立配置，灵活组合，满足不同业务场景

🔁

🔁 自动回复

基于关键词的自动回复，支持文本、富文本、图片和卡片消息。一键配置，即时生效。

📅

📅 定时通知

支持 Cron 表达式，可向指定群或用户每天定时推送消息，不遗漏任何重要通知。

📋

📋 问卷调查

创建投票和问卷，通过飞书卡片发送，实时收集并统计用户反馈。

💬

💬 FAQ 助手

智能问答引擎，支持模糊匹配和多关键词，可处理文本和富文本提问。

🔄

🔄 消息转发

跨群、跨用户消息路由，支持关键词过滤，可用于客服、工单等场景。

🖥️

🖥️ Web 管理后台

可视化配置界面，非技术人员也能轻松管理机器人，无需触碰代码。
